IVI System – Conceptual Architecture

Media + Navigation + Phone Projection (Android Automotive style). Red numbers = data flow; grey text on arrows = interface.

Data flow (example: user taps Play)

  1. Input: touch event goes from InputManager to the Media App.
  2. Service call: the app calls MediaSession transport controls; Audio Focus is requested from AudioService.
  3. HAL: AudioService routes the stream to the Audio HAL, which selects the volume group and zone.
  4. Hardware: PCM data goes over I2S/TDM to the DSP, amplifier and speakers.

Navigation flow: GPS/CAN → GNSS/Vehicle HAL → Location Service → Navigation App → voice prompt via Audio Focus (ducks media). Projection flow: phone → USB/Wi-Fi → Projection Service → video decode and audio to the head unit; touch is sent back to the phone.
